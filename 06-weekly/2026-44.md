## Key learnings
- PowerShell 5.1's `ZipFile.CreateFromDirectory` writes `\` separators into zip entries. The packaging script now names the entries itself with `/`, and has to load `System.IO.Compression` for `ZipArchiveMode`.
- Notarization works end to end: Developer ID signing with hardened runtime, then `notarytool` and stapling. Both the pkg and the dmg were accepted.
- Real-time capture design: a lock-free recorder on the audio thread feeds a take segmenter (play/stop/loop jump). Edge cases worth guarding: offline bounces must not create takes, a NaN ppq block can hide a loop jump, and REC must not reopen armed after a session or preset restore.
- Mid/side width with a low-safe widen can sit in the pipeline's shared tail, and tests prove it matches the old MONO exactly at 0. Old sessions and presets map MONO to 0 / 100 %.
- Host gesture counts can be checked without a DAW by breakpointing `IPlugAPIBase::{Begin,End}InformHostOfParamChangeFromUI` in lldb.
- macOS gives Calendar (EventKit) access to apps, not scripts, so the calendar sync runs inside a small `.app`. MatAnyone 2 on PyTorch MPS runs at about 0.86 s/frame at 1080p, and Otsu thresholding makes a good automatic first-frame chroma mask.
