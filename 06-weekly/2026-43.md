## Key learnings
- Whisper's built-in cutoffs (`compression_ratio > 2.4`, `avg_logprob < -1.0`) make a good hallucination filter for quiet-room mic noise. webrtcvad on a laptop mic picks up a lot of non-speech.
- Licensing building blocks: vendored Monocypher for Ed25519 verification, Base64Url payloads, a machine fingerprint from IOPlatformUUID / MachineGuid hashed with blake2b-256, and a state machine that gates render and drag-out. A Lemon Squeezy refund does *not* disable the license key, so a webhook has to do that.
- MSVC portability gotchas found in CI: `_USE_MATH_DEFINES` is needed for M_PI, and FLAC test material came out different on MSVC and Apple until the test fixtures were pinned.
- Small VPSs (1.9 GB) can't proxy large audio uploads. Presigned PUT/GET straight to R2, verified by checksum and with daily byte reservations, keeps the server out of the data path.
- Real plugin DSP can be compiled to wasm and driven from a browser render worker, so the portfolio demo runs the actual engine rather than a mock.
- Notarization flow for Mac releases: Developer ID Application/Installer signing with hardened runtime, then `notarytool` plus stapling of the pkg and the dmg (in progress, uncommitted).
