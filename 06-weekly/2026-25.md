## Key learnings
- **Drizzle + SQLite wiring for a Next.js app** — `drizzle.config.ts`, a `lib/db/client.ts` store, and a migration chain (`0000`–`0008`) covering subtasks, gratitude/priorities, and week-notes tables. The migrate-as-you-go rhythm held across the week.
- **Selection UX: row-click beats checkboxes.** Clicking a row to select (with a bulk action bar) plus a hover-pencil for rename felt cleaner than checkbox + double-click — a reusable pattern for list-heavy UI.
- **Notebook/paper aesthetic as a layout system.** A 28px baseline grid that every field snaps to, hour-gutter ruling, shaded time-blocks, and a 6-theme paper texture/display-font layer — turning "make it look like paper" into concrete spacing + token rules.
- **TDZ (temporal dead zone) crashes** can silently kill an entire panel on boot — Thursday's Watch-Party `v0.8.4` hotfix was exactly this: a let/const referenced before initialization taking down every button.
- **Firefox/Zen extension build target** — a real second build output with its own manifest and generated icon set (SVG → raster), shipped as Watch-Party `v0.8.3`.
- **Hybrid reverb architecture:** convolution early-reflections feeding an algorithmic tail (Premonition-VST) — a dual-engine approach rather than pure-convolution or pure-algorithmic.
