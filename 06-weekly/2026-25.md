## Key learnings
- **Drizzle + SQLite for a Next.js app** — `drizzle.config.ts`, a `lib/db/client.ts` store, and a migration chain (`0000`–`0008`) covering subtasks, gratitude/priorities, and week-notes tables. Sat also added a SQLITE_BUSY retry on migrations so a fresh-DB `next build` doesn't race.
- **Selection UX: row-click beats checkboxes.** Row-click + bulk action bar + hover-pencil rename felt cleaner than checkbox + double-click — a reusable pattern for list-heavy UI.
- **Notebook/paper aesthetic as a layout system.** 28px baseline grid every field snaps to, hour-gutter ruling, shaded time-blocks, 6-theme paper texture/display-font layer — "make it look like paper" → concrete spacing + token rules.
- **TDZ (temporal dead zone) crashes** can silently kill an entire panel on boot — Thursday's Watch-Party `v0.8.4` hotfix was a let/const referenced before initialization taking down every button.
- **Firefox/Zen extension build target** — a real second build output with its own manifest and generated icon set (SVG → raster), shipped as Watch-Party `v0.8.3`.
- **Hybrid reverb architecture:** convolution early-reflections feeding an algorithmic tail (Premonition-VST) — a dual-engine approach rather than pure-convolution or pure-algorithmic.
- **Packaging Next.js inside Electron** (NEW Sat): bundling the Next.js server alongside Electron for mac + Windows, cross-platform icon pipeline (single SVG → `.icns` + `.ico`), pre-migrate-before-build in CI, and fixing a packaged-server crash rooted in Turbopack/webpack `standalone` output bugs.
- **Cross-platform CI Windows quirks** — `.cmd` spawn handling differs from POSIX `sh` and needed explicit treatment in the desktop build pipeline.
