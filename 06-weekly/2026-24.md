## Key learnings
- **Caddy + Let's Encrypt on Netcup** for HTTPS — DNS gray-clouded, ufw opened on 80/443 — is now a known-working path.
- **yt-dlp + read-only mount gotcha:** the cookies file must be copied into the work dir so yt-dlp's write-back doesn't fail when the mount is read-only.
- **Ableton M4L bridge as Live's transport controller.** The Articulation Roll preview now drives Live's playhead through the M4L bridge rather than running an in-editor-only playback loop — same code path as production playback.
- **Live-apply pattern for Ableton extensions:** write the clip *mid-modal* via `POST /apply` rather than waiting for modal-close, so the user hears edits in real time. This is the new default for any Articulation Roll-style preview UI.
- **Six small "Wave" commits beat one big "Round 2" commit.** Sat night's polish sprint shipped as Waves A–F (one feature each: keyboard input, loop+playhead, legend+status, velocity, snap+legato, wheel-zoom). Each was small enough to revert independently.
- **Notion sync conventions** for the roadmap repo: one-way push from a single source-of-truth markdown file (`screen.md` is the first wired). Doc landed on a branch, not main.
