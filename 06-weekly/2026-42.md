## Key learnings

- A header-only FLAC writer (16/24-bit) is enough for export; extension-aware export names and "a rename or new source writes a new file" avoid stale-take bugs.
- UI robustness patterns: defer UI rebuilds while a control holds the mouse; detect 3D scene changes only in Tick; keep layout/camera math pure so it can be tested.
