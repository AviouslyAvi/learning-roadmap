## Key learnings
- **Alignment is a rebase problem, not a rendering problem.** When the session origin moves earlier, previously-correct take positions become wrong — the fix was to rebase take positions onto the origin (`f3d6ace`) and re-render stems (`fdd368a`), not to re-time at playback.
- **Phase the work so each phase has a named seam.** 2a (take table + block-slice math) → 2b (per-take disk streaming on a worker thread) → 2c (mix into `ProcessBlock`) → 2d (per-take mixer) each shipped as its own PR with a doc commit describing what the next phase inherits.
- **Stream takes off disk on a worker thread**, not the audio thread — Phase 2b exists specifically because the audio callback can't do I/O.
- **A stale build can silently win.** `ed7da7a` warns testers that a leftover 1.0.0 DMG outranks a newer build — version-ordering bites when you're handing binaries to other people.
- **Withdraw advice explicitly when it's superseded.** `0455e52` retracts the "move the manifest" guidance and points at the origin-rebase handoff instead, rather than leaving two contradictory docs in the tree.
- **Ignore local build trees as you create them** (`db116e4`) — `build-2c/` joined the other untracked build dirs the same day it appeared.
