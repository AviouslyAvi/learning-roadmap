## Key learnings
- A bot wall belongs to a path, not to a host, so try fetching the file directly before trusting the page. SSOAR is the exception: its open `/rest/` route returns `[]` to everything.
- Find a host's "no hits" string before trusting an empty result from it, and check every negative against a control.
- A court docket entry is a parent plus attachments. Request `.0` before logging an exhibit 404 as a gap. CourtListener's API returns a normal 401, not a bot wall.
- Unattended loops need a stop policy. Stop on a *confirmed* CI failure. Treat "inconclusive" (timeout, no result yet) as not red, because the macOS runner will legitimately sit queued while the laptop sleeps.
- In PowerShell, anything a function writes to the output stream becomes part of its return value. Diagnostics in a function that returns a boolean have to go through `Write-Host`.
- A design question can sometimes be settled by checking the code first. remote-recording's 3.4 "source selection" turned out to be plugin placement on the mix bus, and the planned input/output swap already did nothing.
