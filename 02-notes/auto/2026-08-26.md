# 2026-08-26 — daily activity

All Premonition today. I loaded the AU in Logic, screenshotted it, and two things were
obviously wrong — the BLOOM knob wasn't animating and the TAIL LENGTH dropdown looked
nothing like Mockup L. Both turned out to be real bugs, and auditing outward from them
surfaced four more transcription mistakes plus a missing animation. The BLOOM one was a
good lesson: `PathStroke` calls `nvgBeginPath` on the way out unless you pass
`IStrokeOptions` with `mPreserve = true`, so the fill after it was drawing onto a path
that no longer existed. The dropdown had to be rebuilt from scratch — iPlug2's stock
`IPopupMenuControl` keeps its geometry members private, so a subclass can only recolour
cells, not restyle the card. One commit, clean builds on all four macOS schemes, not yet
eyeballed. Nothing else touched anywhere in the workspace.
